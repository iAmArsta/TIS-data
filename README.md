# tis-Data
Any collected data in Tehran International School using a Flipper Zero

I used a Flipper Zero during these years and will update if I get anything else. To the best of my knowledge, no other student currently has access to an emulator capable of pulling off these actions. This is for future students.

RFID folder contains any collected RFID tags for school lockers and the elevator, each with the corresponding EM4100 Data

The Sub-GHz folder contains the codes collected on the doors able to be open with a transmitter.

Infrared contains the codes for projectors of classes and auditoriums.
